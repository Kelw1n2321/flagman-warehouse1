# Дизайн-система «Флагман»

Строгий рабочий интерфейс склада: плотная компоновка, границы вместо теней, цвет — только для смысла.
Все значения — CSS-переменные в `frontend/src/styles/global.scss` (светлая тема в `:root`, тёмная в `:root[data-theme='dark']`).

## Цвет

| Роль | Переменная | Назначение |
|---|---|---|
| Фон / поверхности | `--bg`, `--surface`, `--surface-2`, `--surface-3` | фон страницы, панели, подложки, треки переключателей |
| Линии | `--border`, `--border-strong` | разделители, рамки карточек, рамки полей и кнопок |
| Текст | `--text`, `--text-2`, `--text-3` | основной, вторичный, подписи и метаданные |
| Действие | `--primary` | основные кнопки, активная вкладка, фокус, подсветка изменения |
| Норма | `--ok` | доступный остаток, выполненный заказ |
| Предупреждение | `--warn`, `--warn-mark` | истекает срок, малый остаток |
| Критично | `--crit` | просрочка, стоп-лист, отказ, нехватка |
| Нейтрально | `--info` | справочная информация, закрытые статусы |

Красный — всегда критично, жёлтый — всегда предупреждение, зелёный — норма, серый — нейтрально. Цвет статуса
всегда дублируется текстом или иконкой. Других акцентов нет. Графики: `--chart-1..3`, обе палитры проверены
на различимость при дальтонизме и контраст.

## Типографика

IBM Plex Sans — интерфейс, IBM Plex Mono — коды партий и идентификаторы. Все числа — `tabular-nums`.

| Уровень | Размер / начертание |
|---|---|
| Название раздела (шапка) | 18 / 600 |
| Заголовок панели, окна | 15–17 / 600 |
| Название продукта | 15 / 600 |
| Основное число (показатель) | 14–16 / 600 |
| Текст, ячейки таблиц | 13–13.5 / 400–500 |
| Подписи, метаданные | 11–12.5 / 400–600 |

## Форма и плотность

- Радиусы: 3 px — метки и счётчики, 4 px — кнопки, поля, подложки (`--radius`), 6 px — панели и карточки (`--radius-lg`).
  «Таблеток» нет.
- Отступы по сетке 2/4/6/8/10/12/14/16. Карточка: внутренний отступ 12, промежутки 8.
- Тени только у всплывающих слоёв (модальные окна, уведомления, выдвижные панели) — `--shadow-lg`.
  Карточки, кнопки, панели отделяются рамкой `--border`.

## Компоненты

- **Кнопки:** обычная (рамка), основная `btn--blue`, подтверждение `btn--green`, опасное действие `btn--red`
  (контурная), второстепенная `btn--dark` (без рамки), размеры `--sm` и `--lg`.
- **Карточка продукта:** миниатюра, название, категория и артикул, статус, три подписанных показателя
  (доступно / истекает / просрочка или нехватка), партии и ближайший срок, предупреждение о стоп-листе — только если оно есть.
- **Статусы и метки:** прямоугольные, мягкий фон своего цвета + текст.
- **Таблицы:** заголовок 11.5 прописными, строки с разделителями, цвет строки = статус партии.
- **Иконки:** один набор контурных SVG (толщина 2.2). Эмодзи — только как миниатюры продуктов и блюд.

## Движение

Только функциональное, без бесконечных и декоративных анимаций; `prefers-reduced-motion` отключает всё.
Окно: 140 мс появление. Уведомление: 150 мс. Изменившийся остаток подсвечивается рамкой `--primary` один раз (1,6 с).
